# PRD.md — 다시, 한 걸음
## 1. 프로젝트 개요

- **프로젝트명(가칭):** 다시, 한 걸음
- **서비스 유형:** 학습된 무기력·낙관적 사고·그릿을 다루는 심리학 교육 웹사이트
- **주요 이용자:** 학생 및 일반인
- **핵심 목표:** 이용자가 학습된 무기력을 쉽게 이해하고, 하나의 주인공을 따라가는 선택형 2D 상황극을 통해 비관적 사고와 현실적인 낙관적 사고의 차이를 체험하며, 일상에서 시도할 수 있는 행동 전략을 배우도록 돕는다.
- **콘텐츠 원칙:** 쉬운 설명, 실제 연구 근거, 구체적인 생활 사례, 비판단적이고 현실적인 격려를 함께 제공한다.
- **자료 운영 방식:** 사전에 확인한 논문·보고서·공신력 있는 자료를 선정한다. AI는 선정된 자료를 바탕으로 설명문을 쉽게 정리하는 데 사용한다. 웹사이트에서 실시간 논문 검색 기능은 제공하지 않는다.

## 2. 핵심 설계 원칙

1. 전체 페이지는 **3개**로 제한한다.
2. 별도의 검색창, 실시간 검색, 로그인, 사용자 계정 기능은 만들지 않는다.
3. 2D 만화 패널, 대화, 선택 버튼을 활용해 상황극을 진행한다. 복잡한 3D나 고난도 애니메이션은 사용하지 않는다.
4. 낙관적 사고를 권장하되, 무조건 긍정적으로 생각하거나 실패를 개인 탓으로 돌리는 방식으로 표현하지 않는다.
5. 비관적 선택은 ‘틀린 답’이나 벌점으로 취급하지 않는다. 각 사고방식이 감정과 행동에 미칠 수 있는 영향을 설명하고, 다른 선택을 다시 체험할 수 있게 한다.
6. 그릿은 무조건 참고 버티는 태도가 아니다. 목표 조정, 휴식, 도움 요청, 전략 변경도 건강한 대처로 다룬다.
7. 연구에서 확인된 사실, 해석, 예시 상황을 구분하고 출처를 표시한다.

## 3. 사이트 구조 — 총 3페이지

### 페이지 1. 학습된 무기력 이해하기 (`/`)

**목적:** 이용자가 주제를 빠르게 이해하고 상황극에 관심을 갖게 한다.

**구성 요소**
- 상단 메뉴: `이해하기` / `상황극` / `실천하기`
- 첫 화면 제목: “다시 시도할 힘은 어디서 올까?”
- 학습된 무기력의 쉬운 정의
- 학습된 무기력이 생길 수 있는 상황과 관련 요인
- 일상에서 나타날 수 있는 예시: 시험 실패, 발표 실수, 새로운 과제에 대한 포기
- 핵심 개념 카드:
  - 학습된 무기력
  - 비관적 해석과 낙관적 해석
  - 그릿(Grit)
- 관련 연구 요약 2~4개와 출처 링크
- 상황극 페이지로 이동하는 CTA 버튼

**콘텐츠 주의사항**
- 학습된 무기력을 이용자가 스스로 진단할 수 있는 도구처럼 제시하지 않는다.
- 누구나 실패 후 의욕이 떨어질 수 있음을 설명하고, 한 번의 경험만으로 학습된 무기력이라고 단정하지 않는다.
- 연구 결과는 과장하지 않고, 적용 범위와 한계가 확인되면 함께 소개한다.

### 페이지 2. 선택형 2D 상황극 (`/story`)

**목적:** 하나의 주인공이 겪는 상황을 통해 사고와 행동의 차이를 체험하게 한다.

**기본 스토리**
- 주인공은 시험 준비를 했지만 기대보다 낮은 점수를 받는다.
- 주인공은 실망과 좌절을 경험한다.
- 이용자는 주인공이 상황을 어떻게 해석하고 다음에 무엇을 할지 선택한다.

**선택 경로 예시**

**경로 A — 비관적인 해석**
- 생각 예시: “나는 원래 못해. 다음에도 달라지지 않을 거야.”
- 가능한 행동: 공부를 미루거나, 틀린 문제를 확인하지 않거나, 도움 요청을 포기한다.
- 후속 장면: 어려움이 그대로 남을 수 있음을 보여준다.

**경로 B — 현실적인 낙관적 해석**
- 생각 예시: “이번 결과는 아쉽지만, 틀린 부분을 찾아 다른 방법을 시도할 수 있어.”
- 가능한 행동: 오답을 분류하고, 작은 목표를 세우고, 교사나 친구에게 질문한다.
- 후속 장면: 문제를 해결할 기회를 늘릴 수 있음을 보여준다.

**상호작용 요구사항**
- 각 장면은 2D 일러스트 또는 단순한 만화 패널, 짧은 대사, 선택 버튼으로 구성한다.
- 선택에 따라 다음 대사와 행동 장면이 달라진다.
- 마지막에는 두 경로의 생각·행동·가능한 결과를 비교한다.
- `다른 선택 체험하기`와 `처음부터 다시 보기` 버튼을 제공한다.
- 선택을 성격이나 정신 건강 상태에 대한 평가로 사용하지 않는다.
- 결과는 확정적인 예언이 아니라 가능한 흐름의 예시임을 안내한다.

**시각 디자인**
- 따뜻하고 차분한 2D 일러스트 스타일
- 읽기 쉬운 말풍선과 명확한 선택 버튼
- 모바일에서도 패널과 대사가 잘 보이는 반응형 레이아웃
- 장면 전환은 간단한 페이드 또는 슬라이드 정도로 제한

### 페이지 3. 실천하기 — 낙관성, 행동 전략과 그릿 (`/practice`)

**목적:** 상황극에서 배운 내용을 일상에서 활용할 수 있는 구체적인 방법으로 연결한다.

**구성 요소**
- 실패를 경험했을 때 사용할 수 있는 단계별 가이드:
  1. 지금 느끼는 감정을 인정한다.
  2. 일어난 일을 구체적으로 나누어 살펴본다.
  3. 내가 바꿀 수 있는 부분과 통제하기 어려운 부분을 구분한다.
  4. 작고 실행 가능한 다음 행동 하나를 정한다.
  5. 결과를 돌아보고 필요하면 방법이나 목표를 조정한다.
- 구체적인 상황별 예시:
  - 시험 결과가 기대에 미치지 못했을 때
  - 발표 중 실수했을 때
  - 새로운 일을 시작하기 두려울 때
- 그릿 설명: 장기 목표를 향한 관심과 꾸준한 노력. 단, 무조건 버티는 것이 아니라 전략 변경·휴식·도움 요청을 포함한다.
- 간단한 자기 점검 질문:
  - 지금 내가 바꿀 수 있는 작은 부분은 무엇인가?
  - 누구에게 도움을 요청할 수 있는가?
  - 다음에 시도할 수 있는 가장 작은 행동은 무엇인가?
- 관련 논문·보고서 요약과 출처 링크
- `상황극 다시 해보기` 버튼

**주의사항**
- 자기 점검은 진단이나 점수화 도구가 아니라 성찰을 돕는 질문으로 제공한다.
- 심한 무기력이나 일상생활의 어려움이 지속된다면 믿을 수 있는 어른, 학교 상담 담당자 또는 적절한 전문가에게 도움을 요청할 수 있다고 안내한다.

## 4. 자료와 콘텐츠 관리

- 자료는 개발 전에 사람이 확인한 논문, 연구 보고서, 대학·공공기관의 설명 자료를 선정한다.
- 각 자료에 가능한 범위에서 다음 정보를 기록한다.
  - 제목
  - 저자 또는 발행 기관
  - 발행 연도
  - 핵심 내용 요약
  - 원문 또는 공식 페이지 URL
  - 자료가 뒷받침하는 주장
  - 연구의 한계 또는 주의점(확인 가능한 경우)
- AI는 확인된 자료를 쉬운 언어로 바꾸고 요약하는 보조 역할을 한다. 출처에 없는 수치·인용·결론을 만들어 내지 않는다.
- 자료를 확보하거나 검증하지 못한 경우, 임의의 논문명이나 URL을 만들지 않는다.
- 연구 결과와 상황극은 구분한다. 상황극은 교육용 가상 사례이며 실제 개인의 결과를 예측하지 않는다.

## 5. 디자인 가이드

- **분위기:** 따뜻함, 차분함, 희망적이지만 과장되지 않음
- **표현 방식:** 2D 만화 패널, 부드러운 색감, 짧은 문단, 핵심 개념 카드, 명확한 버튼
- **접근성:** 충분한 글자 크기와 대비, 키보드로 조작 가능한 버튼, 이미지 대체 텍스트, 색상만으로 선택 결과를 구분하지 않기
- **반응형:** 데스크톱과 모바일에서 레이아웃이 자연스럽게 바뀌도록 구성
- **공통 UI:** 세 페이지에서 같은 상단 메뉴, 타이포그래피, 버튼 스타일을 사용

## 6. 기술 구현 방향

- **개발 환경:** Google AI Studio에서 웹앱 생성 및 수정
- **프런트엔드:** AI Studio가 지원하는 React 기반 웹앱 구성을 우선 고려
- **상태 관리:** 상황극의 현재 장면과 선택 경로를 프런트엔드 상태로 관리
- **콘텐츠:** 검증한 연구 요약과 상황극 텍스트를 프로젝트 내 정적 데이터로 관리
- **외부 API:** 첫 버전에서는 실시간 검색 API와 데이터베이스를 필수로 사용하지 않는다.
- **배포 목표:** GitHub 저장소 관리 후 Vercel 배포를 고려한다.

실제 생성 환경이 선택한 기술이나 파일 구조와 다르면 기존 프로젝트의 구성을 우선 확인하고, 불필요하게 전체 구조를 바꾸지 않는다.

## 7. 기능 요구사항 및 완료 기준

- [ ] 메뉴에서 세 페이지로 이동할 수 있다.
- [ ] 학습된 무기력의 개념과 원인을 쉬운 말로 설명한다.
- [ ] 연구 요약마다 확인 가능한 출처 링크가 있다.
- [ ] 상황극에서 선택에 따라 장면과 대사가 달라진다.
- [ ] 마지막에 두 선택 경로를 비교할 수 있다.
- [ ] 상황극을 다시 시작하거나 다른 경로를 체험할 수 있다.
- [ ] 실천 가이드와 그릿 설명이 제공된다.
- [ ] 가상 상황과 실제 연구 결과가 명확히 구분된다.
- [ ] 검색창, 로그인, 불필요한 페이지가 추가되지 않는다.
- [ ] 모바일과 데스크톱에서 레이아웃이 깨지지 않는다.
- [ ] 버튼과 링크가 실제로 작동하고, 존재하지 않는 자료나 출처를 표시하지 않는다.

## 8. AI Studio에 전달할 구현 우선순위

1. 세 페이지의 라우팅과 공통 디자인을 구현한다.
2. 페이지 1의 학습 콘텐츠와 검증된 출처를 배치한다.
3. 페이지 2의 선택형 상황극 분기와 다시 보기 기능을 구현한다.
4. 페이지 3의 실천 가이드, 그릿 설명, 연구 자료를 배치한다.
5. 모바일 반응형, 접근성, 링크와 버튼 작동을 점검한다.

**완성 기준:** 화려한 효과보다 정확한 연구 출처, 이해하기 쉬운 설명, 작동하는 선택형 스토리, 실천 가능한 행동 가이드를 우선한다.
